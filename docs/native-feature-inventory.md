## 已确认的重点子系统

### AI 与模型
- 主模型和备用模型配置。
- OpenAI 兼容聊天接口。
- 自定义 JSON 请求头。
- OpenCode 会话标识处理。
- 模型列表拉取与 API 预设。
- 流式输出、推理内容分离、请求取消与错误处理。

### 记忆与世界书
- 传统记忆模式。
- 向量记忆与 Embeddings API。
- Top-K 与最低相似度设置。
- 自动摘要和记忆条目。
- 内置世界书与用户世界书。
- 按用户、角色和对话关联配置。

### 生图
- GPT / OpenAI 兼容图像 API。
- NovelAI 独立接口。
- NAI 官方或第三方代理地址与 Token。
- 模型、正向/反向提示词、细节提示词。
- 尺寸、scale、steps、sampler、cfgRescale、seed、SM / SM Dynamic。
- 参考图/人脸相关路径。
- 图片响应和 ZIP 响应处理。

### 媒体与文件
- 音乐 IndexedDB：`xsj-music`。
- 字体 IndexedDB：`xsj-fonts`。
- YouTube 媒体 IndexedDB：`xsj-yt`。
- 图片、音频、视频、文件导入与导出。
- 原生版需区分数据库记录和真实媒体文件，建立附件索引。

### 通知与后台
- 网页 Notification / Service Worker 通知。
- 主动消息相关定时轮询与间隔任务。
- 音乐播放状态与保活相关逻辑。
- 原生版需使用 Android 通知、WorkManager、MediaSession / 前台服务等系统机制重新实现，不能直接移植浏览器定时器。

## 仍需继续核验

- 通用应用容器实际注册的所有应用名称、图标、入口和 tab。
- Time is Nothing 的所有子页面、状态对象和业务流程。

- 所有网络请求的 endpoint、header、body、response、错误处理。

- CSS 自定义组件与桌面小组件的原生替代范围。
